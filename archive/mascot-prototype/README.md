# Archived mascot prototype

This directory preserves an experimental Unicode pixel mascot that was previously part of NMSh. It includes the sprite definitions, truecolor palettes, animation frames, state machine, renderer/placement helpers, and focused tests.

The mascot is intentionally disabled and has no imports, timers, configuration, rendering, or reserved layout rows in the active application. These files are retained only for possible future experimentation and are excluded from the normal TypeScript build and test paths.
