NMSh remains a terminal frontend around a real persistent zsh, Bash or Fish session. v0.17.0 brings native context routing, richer appearance controls, contextual tools and shell/transcript refinements.

## Highlights

- **Context Engine foundation and Context Rail:** immutable fact metadata, bounded trusted discovery, a native module registry and Surface Router for Main Prompt, Context Rail and Right Context. Rail controls, priority overflow and shared live/preview geometry preserve the independent shell anchor. Repository discovery never executes arbitrary repository-controlled code.
- **Theme Studio and Theme Bridge:** built-in, imported and custom themes; bounded data-only imports; opt-in theming for supported tools through reviewed, NMSh-owned files and environment settings.
- **Contextual `/tools`:** Relevant here discovery from cheap local facts, reviewed package-manager plans, bulk selection and factual activation status. Selection bands remain visible away from focus, including reverse video under `NO_COLOR`.
- **Shell and transcript UX:** `/transcript`, `/layout` and Settings share Normal / Chat presentation. `/shell` clearly distinguishes current, default and keyboard focus; indicator visibility and Left / Right placement share the existing prompt module. Side changes preserve Hidden state.
- **Providers and integrations:** inline provider choices, Oh My Posh support, shell-framework detection, supported tool configuration, tmux Config Studio, integration health and reviewed dotfiles imports. `/btw` is canonical local guidance; `/ask` remains its compatibility alias.
- **Keep Awake:** detected OS backends, optional durations and ownership-verified background processes, with composer, status and idle presentation.
- **Presentation polish:** expanded screensavers, Setup Cat and semantic focus states, Chroma/theme previews, reproducible demos and the hosted reel.
- **Compatibility, updates and hardening:** host profiles, Linux/WSL groundwork, native shell backends, automatic stable-update staging with verification and rollback, and Homebrew provenance protection that prevents the source updater from modifying the Cellar.

## Install and update

### Homebrew

Homebrew is now available and is the recommended install method on macOS:

```sh
brew install raiseCatError/tap/nmsh
nmsh
```

Update with `brew upgrade raiseCatError/tap/nmsh`.

### Build from source

Source installation remains available. Source installs require **Node.js 22+**, zsh by default (optionally Bash 4.4+ or Fish), and the native `node-pty` installation step.

```sh
git clone --branch v0.17.0 https://github.com/raiseCatError/notMyShell.git
cd notMyShell
npm install
npm run build
npm link
nmsh
```

Existing clean official source checkouts can review `/update` and use `/update apply`; automatic updates follow the same checks. Homebrew-owned installs are directed to Homebrew rather than mutated by NMSh.

## Scope and validation

Installable declarative Context Packs, broader capability scheduling and a fuller first-party module catalog remain upcoming; no finalized pack SDK or executable plugin API is shipped.

Full macOS/Ubuntu suites, Node 22 compatibility, Fedora portability, build/type checks and bounded timing smoke passed on the release commit. Linux/WSL and additional terminal hosts have automated/profile coverage; physical validation on those platforms/hosts is not claimed.
