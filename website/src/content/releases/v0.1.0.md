# NMSh v0.1.0

The first public release of NMSh.

NMSh is a terminal frontend for a real persistent zsh session, adding a fixed bottom editor, semantic highlighting, autocomplete, scrollable history, and richer command feedback while preserving normal shell behavior.

## Highlights
- Persistent real zsh session
- Fixed bottom multiline editor
- Semantic command highlighting
- Highlighted submitted-command history
- Shell-aware completion and history suggestions
- Animated command lifecycle feedback
- Scrollable history viewport
- Fullscreen application passthrough
- Ghostty keyboard and appearance integration

## Compatibility
- macOS
- zsh
- Ghostty is the primary development host
- macOS Terminal and VS Code terminal have partial/documented compatibility

## Known limitations
- Native mouse / Shift-drag selection behavior still has rough edges
- Complex third-party ZLE UI plugins are not directly portable
- Zsh semantic highlighting is intentionally not a complete parser
- Multi-shell support is future roadmap work
