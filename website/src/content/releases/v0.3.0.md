This GitHub/source release completes the **v0.3.0 Session & Interaction UX** milestone. The final candidate passed human visual and interaction validation in Ghostty, Terminal.app, and VS Code integrated terminal.

### Highlights
- **Prompt and appearance:** NMSh Native, optional Starship and Powerlevel10k prompt providers; five Native themes; independent Start, Connector, Gap, and End geometry; configurable icons and module manager.
- **Composer and history:** one-line and two-line layouts, historical semantic prompt snapshots, and `/transcript` controls for dividers, prompt visibility, color, and density.
- **Session interaction:** `/clear` archives history without replacing the live zsh; `/resume` restores archives; `/zsh` hands off to ordinary interactive zsh; nested NMSh is rejected.
- **Input and activity:** exact-source rich paste atoms, nested activity rows for observed Node TAP streams, and a fresh-session welcome header with build identity.
- **Version identity:** `/version` and `--version` expose `notMyShell 0.3.0`.
- **Final passive-hover fix:** the last release-candidate fix preserves ordinary terminal text selection while providing optional passive hover feedback where the terminal host supports it (PR #82).

### Known limitations
- Native `fzf-tab` support remains future work (#52).
- Powerlevel10k does not reproduce its right prompt, gitstatus daemon, instant prompt, or settings defined only in `.zshrc`.
- Nested activity covers directly observed Node TAP v13 streams.

The release candidate passed `npm ci`, build, typecheck, 239/239 automated tests, the slow TAP fixture (2/2), diff check, and build identity verification. Release PR CI passed on Node 22 and Node 26. The package is private; no npm publication was performed.
