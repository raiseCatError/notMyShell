# notMyShell v0.16.0

NMSh grows into a more complete workspace around your real shell: live sessions, agent activity, richer completion, local help and a calmer, more configurable interface. This release brings the work planned across v0.8–v0.15 together with v0.16.

## Highlights
- Switch between zsh, Fish and Bash without giving up the NMSh composer and transcript.
- Find live sessions, track attention and inspect agent activity.
- Explore richer completion, smarter history and local Ask.
- Customize appearance, cursor effects and Clean or Rich motion through expanded Setup.

## Shells & sessions
`/shell` supports zsh, Fish and Bash 4.4+, with a default-shell setting for new sessions. Persistent sessions keep commands running when a window detaches; `/resume` and `/sessions` show factual state and duration. Short-lived notices surface changes in other sessions. `/agents` offers local activity statistics, while `/ai` brings managed and observed agent sessions into view.

## Ask, completion & tooling
Ask explains NMSh capabilities, with optional local Qwen understanding configured through `/llm`. Downloads always require confirmation. Completion combines live shell knowledge with static Fig and Carapace data and custom specs. History gains context ranking and filters. Optional providers, project tasks, mise awareness, `/watch` and a curated `/tools` catalog help with everyday work.

## Appearance & interaction
`/appearance` brings prompt, cursor and motion controls together. Clean and Rich motion have their own tuning; cursor effects use portable rendering or supported host integration. Expanded Setup, grouped Config and Status, paste preview and review, transcript find/filter, editor opening and diff viewing make the interface easier to navigate. Images and links use capability checks and fallbacks.

## Maintenance / portability
`/doctor` reports local diagnostics. Export/import moves settings between machines, and uninstall previews launcher removal while keeping data by default. Linux/WSL groundwork and host capability handling are included; physical Linux/WSL and additional terminal-host validation remains follow-up work. Host-specific effects depend on what your terminal supports.

## Upgrade
From a clean official source checkout, use `/update`, review the plan, then `/update apply`. Restart NMSh to load the new build. Existing configurations are preserved and migrated where needed; updating does not replace your shell profile or remove transcripts. Older session services keep their live sessions running, but a newer frontend may not attach to sessions from an incompatible protocol version. Finish those sessions with the older frontend if needed.

Source installs require Node.js 22 or newer: `npm install` followed by `npm run build`. The package remains private and is not published to npm.
