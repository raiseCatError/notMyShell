This GitHub/source release introduces the **v0.2.0 Structured Execution** milestone, focusing on intelligent output presentation and factual lifecycle feedback.

### Highlights
- **Structured Presentation**: Dynamically categorizes PTY execution into INLINE, FOLDED, LIVE, and PASSTHROUGH modes based on output behavior.
- **Output Folding**: Long, noisy output is automatically folded. You can expand/collapse specific commands via local click controls or toggle global details using `Ctrl+O`.
- **Full PTY Preservation**: Raw output is preserved completely—using `/copy` correctly captures all hidden/folded lines without presentation chrome.
- **Factual Command Lifecycle**: Replaces arbitrary loading messages with deterministic status reports (e.g., `Running npm test`).
- **Deterministic CLI Summaries**: Specialized output adapters silently parse output from tools like `npm`, `jest`, `mocha`, `git`, Node TAP, and `brew` to render concise rich status summaries (e.g., `142 passed`).
- **Native Selection Preservation**: Shift+drag native terminal text selection is safely maintained alongside NMSh's interactive features.
- **SemanticService Resilience**: Hardened background completion/highlighting service to safely bypass host-specific interactive initialization (e.g. macOS `Terminal.app`) and prevent deadlocks on unexpected exits.
- **Validated Compatibility**: Human-verified PASSTHROUGH support for interactive TUIs (`vim`, `nano`, `fzf`), and robust runtime stability across Ghostty, macOS Terminal.app, and `tmux`.
