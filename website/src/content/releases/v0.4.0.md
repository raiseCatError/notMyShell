NMSh v0.4.0 brings a richer, context-aware prompt, calmer command output, and a new settings, session, and update foundation.

## Highlights

### Prompt
- **Right-side prompt context:** any module can sit left or right (`/prompt` → Modules, `P`). The right side mirrors its geometry to face left by default (`M`) and is the first thing dropped on narrow terminals.
- **Show-on-command modules:** Kubernetes and Docker context, and optionally toolchains, appear only while a relevant command is typed. Typed text is never executed.
- **Intelligent directory shortening:** a width-aware path that keeps the repository name and current directory whole.
- **Richer Git state:** staged, modified, untracked, conflicts, ahead/behind/diverged, operations, and a clean marker, with a dedicated Rich Git view. Also new: connector fade, fade colors, and Gap Wide.
- **Deterministic prompt showcase** in `/prompt`, rendered by the real renderer.
- **Starship module editor** with previewed, confirmed, and backed-up changes, plus a **Powerlevel10k configurator handoff**.

### Output and history
- **Smart output folding:** long, repetitive successful output folds to its first 3 and last 5 lines, while failures and useful output stay expanded. Ctrl+O expands, and `/copy` and `/resume` keep the full output (Config → Output folding: Smart / Never).
- **Sticky command headers** while scrolling.
- **Continuous session journal and advanced `/resume`:** interruption-safe checkpoints, search, and day/week/month navigation.

### Editor, settings, and tooling
- **Theme-aware syntax highlighting** and `/syntax`.
- **Central `/settings`** (Settings / Status / Config) on a shared panel shell with consistent Esc/back navigation.
- **Glyph compatibility choice** (Nerd Font or Safe/ASCII) on first run, persisted.
- **Reusable task progress** for long-running installs.
- **`/update`** reports newer releases and safely updates a clean official source checkout. Background checks are opt-in.
- Compatible zsh hooks from your own config (zoxide, Atuin) keep working, and shell-theme prompts no longer leak into command output.

## Known limitations
- Configured-zsh completion parity and `fzf-tab` interoperability are not supported yet (#52).
- Command-completion desktop notifications are not part of this release.
- Powerlevel10k: NMSh shows only its left prompt. The right prompt, gitstatus daemon, and instant prompt are not reproduced.
- Nested activity is limited to directly observed Node TAP v13 streams.
- `/update apply` automates only clean source checkouts of the official repository.

Validated in Ghostty. No npm package is published. Full notes are in [CHANGELOG.md](https://github.com/raiseCatError/notMyShell/blob/v0.4.0/CHANGELOG.md).
