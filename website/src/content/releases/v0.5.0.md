NMSh v0.5.0 brings predictive suggestions, new layouts and presentations, a command palette, and a shared provider framework.

## Highlights

### Suggestions
- **NMSh Native Suggestions v2:** ghost text ranked by fuzzy and acronym matching, frecency, the current directory, and what usually follows your previous command. → / End accepts, Alt+→ accepts the next word, Ctrl+N / Ctrl+P show ranked alternatives, and Esc dismisses. Empty-prompt prediction is optional. Everything stays local, and leading-space and `HISTORY_IGNORE` commands are never suggested.
- **Optional Deja provider:** uses an installed [Deja](https://github.com/Giammarco-Ferranti/deja) while NMSh draws the ghost text. It falls back to Native if Deja is missing or unhealthy.

### Layout and presentation
- **Dock Top:** put the composer at the top (Config → Composer position). The newest output and live activity stay together.
- **Chat presentation:** commands align right and output stays left (Config → Transcript presentation). It works with Top or Bottom, and stored transcripts and `/copy` are unchanged.
- **Command palette:** `/palette`, F1, or Ctrl+Shift+P to search NMSh commands, settings, and actions. It only runs NMSh actions, never shell text.

### Providers and prompt
- **Welcome providers:** Vespyr (default), Fastfetch with your own configuration, Neofetch (legacy, if installed), or None. `/resume` keeps each session's original welcome.
- **Shared provider gallery** in `/settings` with installed/missing/version status, previews, explicit install confirmation, and safe fallback.
- **Native prompt styles:** Powerline, Soft, Minimal, and Outline, with Safe glyph fallbacks.

### Output
- **Output folding modes:** Off, Smart (default), and Always.

### Fixes
- NMSh-owned Homebrew installs find `brew` in its standard Apple Silicon and Intel locations.
- Right-aligned Chat commands keep their final character at the terminal's last column.
- The command palette list stays stable and scrolls only at its edges.

## Known limitations
- Completion, richer History, and Picker providers are future work. Configured-zsh completion parity and `fzf-tab` are not supported yet (#52).
- Flow / Classic composer mode and persistent live sessions are not included.
- Deja is optional and not bundled. Neofetch is archived upstream and never installed by NMSh.
- NMSh renders with truecolor. There is no separate 256-color mode.
- Command-completion desktop notifications are not part of this release.
