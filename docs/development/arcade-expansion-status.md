## Verification on the branch tip (working tree, before commit)

- `tests/arcadeAll.test.ts` is the cross-game regression file: metadata, garbage records, render matrix, resize, dispose, pause, key ownership (including Driftkeys: no echo and nothing recorded), previews, v0.22 save migration, and an offline source scan (no network, `child_process`, `fs` or timers in games).

## Performance (measured, not gated)

Node v26.12.0, Apple M2 with 8 GiB, measured while the machine was heavily loaded by other jobs, so means are upper bounds. Script: `scripts/arcade/perf.ts`; raw results were kept on the scratch volume and are not committed. The frame budget used for comparison is 33 ms (the session's 30 fps tick). No arcade-specific thresholds exist in the repository (`docs/performance-benchmarks.md` only has 16 ms editor-frame investigation targets), and none were invented.

Total ms per frame, mean / p95:

| Scene | 100x34 | 160x50 |
|---|---|---|
| Hub, idle | 2.37 / 3.4 | 4.32 / 5.9 |
| Hub, animated preview | 2.55 / 4.4 | 4.14 / 5.5 |
| Vespyr Pinball | 2.10 / 3.3 | 3.52 / 5.2 |
| Vespyr Rover | 2.53 / 3.6 | 6.10 / 9.9 (one 95 ms outlier, 6 frames over 33 ms; not reproduced) |
| Sandfall | 1.94 / 2.8 | 3.68 / 7.2 |
| Kitten Parade | 2.25 / 3.6 | 4.44 / 7.8 (a forced 500k crowd was no slower: drawing is capped) |
| Driftkeys | 0.61 / 0.69 | 0.63 / 0.75 |

- **Moonjars is the consistent outlier**: about 7-8 ms mean alone at 100x34, p95 9-16 ms, a few frames over 33 ms. Not measured at 160x50. Its target search is capped (about 120 ms per phase).
- Heap stayed flat over 300 simulated seconds: Pinball 23.7 to 23.6 MB, Rover 23.3 to 23.4, Sandfall 23.4 to 23.6, Parade 23.4 to 23.5, Driftkeys 23.2 to 23.2.
- 200 open/dispose cycles left no timers or handles and heap grew by at most 0.1 MB.
- Games not listed were smoke-rendered only, not timed.

## Residual limits (not harmless)

- **Pinball**: the table is 0.65 scale at 100x34; a flip-on-contact bot can cradle the ball indefinitely; no held flippers (terminals send no key release) and no extra ball; the game-over dialog score counts up from 0, so still captures look wrong.
- **Rover**: backflips are essentially impossible; tilt response was raised so a 6-8 taps/s driver flips off real jumps (59, 65 and 69 of 80 seeds).
- **Kitten Parade**: greedy-per-row is provably optimal, so a skilled player wins every level (easy but fair); the LEVEL CLEAR popup duplicates the banner; large crowds merge into a slab.
- **Vespyr Leap**: the ready hint can overlap a platform; the narrow cat is wider than a platform.
- **Ice Paws** has no mouse support. **Treat Match**: the hint ring has low contrast and same-kind 6px sprites touch.
- At 28 columns the top-row text truncates in Treat Match, Merge 2048, Ice Paws and Moonjars.
- Classic Minesweeper Expert at 100x34 uses a 60x16 board. Sudoku needs 20x13.
- **Merge 2048** cannot undo after game over. **Yarn Lines**: a hint replaces a valid but different path.
- **Moonjars**: hard decks often have an unproven target, and the solver deadline uses `Date.now()`.
- **Catapult Cats**: blocks do not rotate; later-level solvability is unproven.
- **Sandfall**: the well is fixed at creation. **Cat Fleet** and **Driftkeys** have no daily seed.
- Pinball, Catapult Cats, Rover and the other newer games have never been played by a person apart from the maintainer's reported feedback pass (see the log).
- Visually unreviewed: most helper-written games beyond those marked in the table.

Known limits (recorded, not hidden):

- Over a running command the Arcade opens only by Ctrl+T. Typing `/games` into a running program is still that program's
  input, by design.
- Ownership evidence is the session's `InputState` (InputWatch). A program that reads the keyboard without the session ever
  reporting it (a read that starts between samples) can be open under a game for up to one sampling window before the
  report arrives; when it does, the game pauses and the strip says so. No key is ever forwarded in that window, but the
  person must leave the Arcade (Ctrl+C) to answer it. The existing likely/confirmed wording is used as is.
- A command that starts from type-ahead or another window still closes the Arcade (unchanged).
- The 14 row x 40 column minimum for the strip; smaller terminals show a one-glyph marker plus the unread count instead.
- Ghostty/Zed behavior of Ctrl+T (the byte `0x14` / Kitty `CSI 116;5u`), toast legibility on the real fonts and the feel of
  the slide are unverified by a person.
