Heap stays flat across frames (the cell grid is reused), and an unsubscribed
scene leaves the presentation clock with no subscribers and no timer. Aurora's
terminal output (~450 KB/s at 120×40) is the heaviest; it was reduced ~35% by
quantization and blank-cell escapes. Physical CPU use per host is part of
physical QA.

The full `npm run bench`, presentation and platform benchmark scripts were
run and completed; their numbers are informational.

### Real-app check

NMSh was run in tmux at 120×40 with truecolor; `/screensaver start aurora`
drew a full-screen Aurora Drift in the Aurora Chroma palette, and one key
restored the prompt and composer. VHS 0.12.0 on the development machine
reports success without writing files (a known issue noted in
dev/tapes/README.md); the idle tapes validate and should be recorded with VHS
0.12.1 or later.
